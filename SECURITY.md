# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Email `ray.hung@stanford.edu` with:

- a description of the problem and its impact
- affected versions and Android versions
- reproduction steps or a proof of concept
- any suggested mitigation

Do not include signing keys, passwords, private wallpaper images, or other unrelated sensitive data. You should receive an acknowledgement within seven days.
